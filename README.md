# aarch64-purecap-rt

Library for a simple startup routine for CHERI Aarch64 (ARM Morello architecture) pure capability bare-metal applications.

## Getting started

See [QUICKSTART.md](./QUICKSTART.md#getting-started) for how to install and use the `crability` tool.

Example applications that use the runtime can be found in the [aarch64-purecap-examples](https://github.com/sabikura/aarch64-purecap-examples.git) repository.
